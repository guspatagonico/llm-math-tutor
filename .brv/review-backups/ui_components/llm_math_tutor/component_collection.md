## Narrative
### Structure
The `src/components` directory contains a collection of modular React components for the LLM Math Tutor application. These components handle UI rendering, mathematical equation display, user interaction, and SEO.

### Dependencies
React, KaTeX for math rendering

### Highlights
AITutorChat: Core component for the AI tutor chat interface.
MathEquation & MathMarkdownRenderer: Handle rendering of mathematical content.
HomeLearningPath & PathwayBanner: Components related to the user's learning path.
SigmoidLogitModule, SoftmaxGradientModule, TemperatureSimulator: Interactive modules for specific math concepts.
SeoBlocks: Renders SEO-related metadata blocks.
