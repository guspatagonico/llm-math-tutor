### Key Points
- This document outlines the constants used throughout the frontend application.
- Constants are centralized in the `src/constants` directory for easy management.
- They are organized by feature into separate files.
- Key areas covered include chart configurations, learning paths, application routes, SEO metadata, and AI model temperature settings.
