# Frontend Types

This domain contains application-wide TypeScript type definitions, organized by domain within the `src/types` directory. For detailed definitions, see `frontend_types.md`.

-   **API Types (`src/types/api.ts`):** Defines types for API request and response payloads.
-   **Math Types (`src/types/math.ts`):** Contains types and enums for mathematical concepts.
-   **Main Entry (`src/types/index.ts`):** Serves as the primary export point for all application types.
