## Utilities (`utils`)

The `utils` domain contains modules with reusable helper functions.

### Mathematical Utilities (`utils/math`)

This section, detailed in `mathematical_utility_functions.md`, provides pure mathematical functions for machine learning from `src/utils/math.ts`. It includes core operations like `sigmoid`, `logit`, and `softmax`, with a key feature being temperature scaling in the `softmax` function to adjust model prediction randomness. An educational function, `normalizeSteps`, breaks down the softmax calculation.
