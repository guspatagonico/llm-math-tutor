## Mathematical Utilities (`utils/math`)

This module provides a collection of pure mathematical utility functions for machine learning concepts, sourced from `src/utils/math.ts`.

-   **`mathematical_utility_functions.md`**: Documents core functions such as `sigmoid`, `softmax`, `softmaxJacobian`, and `logit`. A key feature is the inclusion of temperature scaling within the `softmax` function to control the randomness of model predictions. The `normalizeSteps` function offers a detailed breakdown of the softmax calculation for educational purposes.
