# Project: LLM Math Tutor Overview

This domain provides a high-level summary of the LLM Math Tutor project, an educational web application for teaching math concepts to LLMs. The primary documentation can be found in `llm_math_tutor.md`.

-   **Architecture**: The application is a Single Page Application (SPA) using hash routing, with a backend powered by Express.
-   **Technology Stack**:
    -   **Frontend**: React 19, TypeScript 5.8, Vite 6, and Tailwind CSS 4.
    -   **Integrations**: Utilizes the Gemini API, with KaTeX for rendering math equations and Recharts for visualizations.
-   **Features**: Includes educational modules for Sigmoid/Logit, Softmax, Temperature, and an AI Tutor.
