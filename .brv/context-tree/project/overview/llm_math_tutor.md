## Narrative
### Structure
The application is a Single Page Application (SPA) using hash routing, with a backend powered by Express.

### Dependencies
The frontend uses React 19, TypeScript 5.8, Vite 6, and Tailwind CSS 4. The backend uses Express 4. It integrates with the Gemini API and uses KaTeX for rendering math equations and Recharts for visualizations.

### Highlights
Features several educational modules: Sigmoid/Logit, Softmax, Temperature, and an AI Tutor.
