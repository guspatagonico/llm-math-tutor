# Project Domain: LLM Math Tutor

This domain contains general information about the LLM Math Tutor project, focusing on its architecture, technology stack, and key features, as detailed in the `overview/llm_math_tutor.md` entry.

*   **Architecture**: The project is a Single Page Application (SPA) built with hash routing and an Express backend.
*   **Technology Stack**:
    *   **Frontend**: React 19, TypeScript 5.8, Vite 6, Tailwind CSS 4.
    *   **Integrations**: Gemini API for AI capabilities, KaTeX for math rendering, and Recharts for visualizations.
*   **Key Features**: The application includes educational modules for concepts like Sigmoid/Logit, Softmax, and Temperature, alongside an AI Tutor feature.
